## 需求优先级与图像冲突

1. 已确认 PRD v1.1 的交互/权限/异常规则及其后续显式确认 > 本文件 > 视觉基准图片中偶发的文本/位置。
2. 初始页：MQ Logo **位于页面中央偏上**；左侧半透明 MQ/M/Q 导航、右上登录/注册可见。故事星是明显可交互星点、背景星尘不可交互；只有故事星和篝火能打开故事。
3. 点击星星/篝火后：**仍使用 A 的同一幅 MQ 夜景、同一情侣和篝火位置**，只将背景加深；中心显现 B 样式羽毛信。不得把 B 的背景景色替换成新场景。
4. 阅读期间：**左侧导航与右上角常规登录入口完全隐藏**。B 的左上 MQ Logo、左侧导航、右上登录/注册等是绘图未完全遵循后续 PRD 的痕迹，不能照搬。MQ Logo 不必在信纸顶端重新出现。
5. 信纸定位：屏幕水平居中且视觉上垂直居中；桌面上四周仍有变暗的首页。正文、图片、点赞、留言和评论全在**同一张信纸、同一纵向滚动流**。展开从上往下平滑舒展，不是卷轴。
6. A 与 B 中的文章标题、日期、姓名、评论内容和数量是演示信息，不可作为真实数据要求；不可凭概念图片冻结移动端布局、动画毫秒参数或故事目录的位置。
7. A/B 图片中已绘制的字样与控件**不可以作为真实网站可操作文字/按钮**。Web UI 应由可访问的 DOM/SVG/独立资产承载，避免一张含有 Logo/按钮的整图做背景造成重复或虚假交互。

## 素材工程边界

- 原图属于视觉验收参考图，不是已分离的透明图层。请先审查可用图层资产，必要时制定“去 UI 的夜空/地景底图、独立情侣人物层、可独立改变火焰与暖光的篝火层、单独 Logo 与导航、星尘/故事星覆盖层”等素材制作方案。
- 不是要求每一根草都独立动画：远处静景可以合成为底图，**影响实际动效或交互的元素必须独立**。
- 不要将 A 或 B 整张原图当作成品网站的单张背景来宣称分层完成；不应试图通过贴透明按钮冒充交互层。
- 若只能生成临时近似素材，应在 PR 中注明素材差异和未验收内容，不因 `npm run check` 通过便宣称视觉完成。
- 用户上传的个人真实照片不包含在交接包里；不得自动复制这些原始照片进 GitHub。
