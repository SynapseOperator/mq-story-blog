# MQ 共享主页 · 可交互原型验收清单 v1.0

> **基线文档**：《MQ 共享主页 PRD v1.1》｜**状态**：待执行（本清单不代表任何项目功能已实现）  
> **验收阶段**：A 为第一阶段交互原型；B 为原型后真实功能开发；C 为软件工程课程的 DevOps 交付。  
> **记录方式**：逐项勾选，填写测试设备、演示地址、截图/视频、失败复现步骤及对应 GitHub Issue。

## A. 第一阶段交互原型（可使用明确标注的演示数据）

### A1. 页面与视觉

- [ ] **UX-01**｜首次打开网站进入 MQ 初始主页，看到星空、茂盛青草山坡、情侣、篝火；无萤火虫。
- [ ] **UX-02**｜MQ 艺术 Logo 位于中央上方；初始主页左侧为 MQ/M/Q 半透明固定导航，右上角有账号入口。
- [ ] **UX-03**｜点击 M 或 Q 进入对应“建设中”的初始占位页；初始页保留导航且可以返回 MQ。
- [ ] **UX-04**｜导航、账号入口、Logo 均不随鼠标视差偏移。
- [ ] **UX-05**｜视觉概念图中湖泊、村镇、灯具等并非必须；页面不得出现萤火虫或新增故事热点。

### A2. 星空与篝火

- [ ] **UX-06**｜背景星尘低亮度、不可点；明显故事星可点、有对应故事。
- [ ] **UX-07**｜鼠标悬停故事星，光晕变化并显示该篇标题；不同星打开不同故事。
- [ ] **UX-08**｜鼠标移动时出现轻微视差；星星点击区域与可见星同步，不会错位。
- [ ] **UX-09**｜篝火悬停时火焰和周围暖光**明显增强**，移开自然恢复；木柴不整体放大。
- [ ] **UX-10**｜点击篝火只打开《我们在一起的故事》这一特殊文章。

### A3. 羽毛信与阅读状态

- [ ] **UX-11**｜点击入口后背景变暗，左侧导航和右上角常规登录入口隐藏。
- [ ] **UX-12**｜信纸在屏幕中央**由上向下平滑舒展**，未使用折痕逐段翻转或木轴卷轴效果。
- [ ] **UX-13**｜信纸采用浪漫的欧洲复古旧信质感，旧纸纹理不妨碍中文正文阅读。
- [ ] **UX-14**｜羽毛信不占满桌面屏幕；背景场景保留，正文、图片、点赞和「留言」同纸连续滚动。
- [ ] **UX-15**｜信纸内部滚动时，背景不跟随滚动；长文不使信纸无限超出屏幕。
- [ ] **UX-16**｜点击关闭按钮、外围暗区或按 Esc 能关闭信纸并恢复首页与导航。
- [ ] **UX-17**｜有尚未提交的留言输入时尝试关闭，弹出确认；取消后原输入仍保留。
- [ ] **UX-18**｜连续快速点击不会出现多封信纸或重复弹窗。

### A4. 移动端、目录和降级体验

- [ ] **UX-19**｜触屏点按故事星能直接读信，不依赖鼠标悬停。
- [ ] **UX-20**｜移动端存在**可收起的回忆目录**，选择标题能打开相同的羽毛信；目录入口位置尚待整体 UI 评审，不因此锁定。
- [ ] **UX-21**｜移动端无严重横向溢出，信纸正文/留言可阅读，关闭按钮可操作，点击区域不明显重叠。
- [ ] **UX-22**｜启用减少动态效果后，仍可完整打开、阅读和关闭故事，复杂位移动效得到简化。

### A5. 原型验收特有约束

- [ ] **UX-23**｜所有演示故事、账号、留言与状态均标注“模拟/演示”，未将静态假数据冒充真实数据库。
- [ ] **UX-24**｜按此 PRD 评审后，记录需要调整的颜色、字体、尺寸、展开节奏及移动端目录布局。

## B. 完整应用功能验收（不得用纯 UI 原型冒充）

- [ ] **FN-01**｜普通用户可使用用户名、密码注册、登录与退出，不能注册成管理员。
- [ ] **FN-02**｜网站仅有一个受控管理员账号；普通用户访问后台页面或接口均被服务器拒绝。
- [ ] **FN-03**｜未登录用户在羽毛信内点击点赞，出现信纸上方登录子弹窗；取消或登录后**文章及滚动位置不丢失**。
- [ ] **FN-04**｜登录账号对同一篇文章最多有一个有效点赞；可取消；刷新后点赞状态正确。
- [ ] **FN-05**｜游客无需登录即可匿名提交留言；已登录用户也需接受审核。
- [ ] **FN-06**｜管理员通过留言后才公开；未审核、拒绝或撤回的留言不出现在公开列表。
- [ ] **FN-07**｜留言发送失败保留文本，可重试，短时间重复点击不产生多条意外重复留言。
- [ ] **FN-08**｜管理员可创建草稿、编辑文章、选择预设空星位、预览并发布，新故事出现在对应星星上。
- [ ] **FN-09**｜服务器阻止一颗预设星位被两篇故事占用；既有文章的位置不会被意外替换。
- [ ] **FN-10**｜下架故事后对应星星和目录条目隐藏；重新发布后仍能恢复原绑定。
- [ ] **FN-11**｜篝火独立绑定《我们在一起的故事》，不会被普通星位发布流程覆盖。
- [ ] **FN-12**｜每篇已公开故事有独立可分享 URL；点击首页故事后地址更新，浏览器后退回到首页。
- [ ] **FN-13**｜外部直接打开/刷新故事 URL，加载 MQ 场景暗化背景和同一羽毛信；导航保持隐藏。
- [ ] **FN-14**｜草稿、已下架、错误 URL 不返回非公开正文，显示友好提示并能回到 MQ。
- [ ] **FN-15**｜空故事状态仍呈现夜景，但不存在能点击后打开空内容的故事星；没有已发布特殊故事时篝火不能打开空文章。
- [ ] **FN-16**｜图片失败不破坏全文阅读；网络请求失败有提示、重试和安全返回。
- [ ] **FN-17**｜对评论文本进行安全展示，执行基本限流与输入检查；管理员账号密码妥善保护。
- [ ] **FN-18**｜公开内容由双方确认适合分享，私密真实素材不混入课程演示资源。
- [ ] **FN-19**｜数据持久化、重启后内容保持一致；至少演练一次备份恢复。
- [ ] **FN-20**｜发布新的博客故事不需要修改代码或重新运行部署流水线。

- [ ] **OPS-02**｜分支开发、Git 提交与 Pull Request 互审有真实历史记录。
- [ ] **OPS-03**｜代码检查与自动化测试可追溯到 GitHub Actions 构建记录。
- [ ] **OPS-04**｜已配置可展示的自动构建/持续集成流水线与发布产物。
- [ ] **OPS-05**｜真实部署地址可访问，运行环境与部署配置留有可核对的证据。
