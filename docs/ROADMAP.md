# 可以一起改善的地方

MQ Story 首先是一份可运行的自托管工程参考。后续改进会优先降低阅读和复现成本，再考虑把它做成通用博客模板；这里列的是方向，不是发布时间承诺。

| 方向 | 适合怎样参与 | 开始前需要明确什么 |
| --- | --- | --- |
| 英文开发文档 | 逐节翻译开发指南，核对实际命令；适合作为首次贡献 | 与中文当前版本对应，保留配置前提和失败说明 |
| 本地演示体验 | 在不同系统实跑，反馈启动时间、报错和停止恢复体验 | 注明 Docker/Compose 版本；不要提交演示口令或数据卷 |
| 开放许可的默认主题 | 用 CSS/SVG 制作星空与简单信纸，让独立自托管不依赖原站美术授权 | 先讨论视觉与可访问性方案；原站主题和素材许可保持不变 |
| 星位配置化 | 将数量和响应式坐标从固定布局中提取 | 数据库约束、后台预览和首页必须保持一致，需要迁移设计 |
| M / Q 入口 | 讨论这两个入口实际承载的内容与隐私边界 | 目前仍是建设中页面，不预设公开个人资料 |
| 分享卡片 | 为公开故事设计不泄露草稿或私人图片的 Open Graph 预览 | 是否搜索收录是独立决定，当前 noindex 不随卡片改动自动取消 |

文档翻译和清楚的复现报告通常不需要大改代码。默认主题、星位模型和 M/Q 功能请先开 Issue 讨论，再写实现。贡献流程见 [CONTRIBUTING.md](../CONTRIBUTING.md)。

## 版本发布

网站上线日期不等于可复用模板的稳定版本承诺。首个正式 GitHub Release 将在本地演示和公开运行说明通过评审后确定，标签绑定实际提交，并附迁移、素材许可与部署说明；不会回填一个未经验证的历史 v1.0.0。
