# Issue #2 场景素材

2026-10-22 已接入用户提供的 7 张 PNG 的 WebP 版本，独立素材缺口已解除。按 [正式基准 A](../../docs/product/visual-baseline-v1.0/VISUAL_HANDOFF.md) 返工的 Issue #2 已获用户明确视觉及评审通过，PR #5 已合并。Issue #3 复用以下素材，动效的视觉与交互验收仍须单独进行。检查结果和评审记录见 [Issue #2 验收记录](../../docs/engineering/ISSUE_2_REVIEW.md)。

本轮来源为用户提供的图片，不冒称第三方开源素材或从 A 逐像素拆出的原始图层。原始下载 PNG 保持原样、不提交；本轮只提交用于网页的 WebP。编码使用 Sharp，参数为 `quality: 92`、`alphaQuality: 100`、`effort: 6`，没有缩放、重绘、AI 生成或自动抠图。所有输出均为 **1536 × 1024**，共 **1,503,134 bytes**，由本地路径提供。

Issue #3 清晰度反馈后，为像素密度至少 1.5dppx 的竖屏额外提供以下两份无损网页编码。它们来自同一原始 PNG，使用 Sharp `lossless: true, effort: 6`，没有放大或锐化；解码后逐像素核验可见 RGB 与 alpha 均与原图一致。`picture` 根据媒体条件选择资源，普通密度或横屏继续使用原有轻量版本，重复图层复用同一 URL。

| 高密度竖屏资源 | 像素尺寸 | bytes |
| --- | --- | ---: |
| `night-sky-lossless.webp` | 1536 × 1024 | 1595200 |
| `grassy-hillside-lossless.webp` | 1536 × 1024 | 1079970 |

代价是高密度竖屏首次加载的场景图片从约 1.50 MB 增至约 3.50 MB。媒体条件稳定时首次加载只请求匹配版本；旋转屏幕或媒体条件变化后可能追加另一版本。无损编码消除额外压缩损失，但不增加原始细节：390×844、DPR 3 下，竖屏画板对应 3798×2532 设备像素，现有背景仍只有 1536×1024；若需进一步提升远景/草地的真实清晰度，需要更高分辨率的同构图源图。源图自带的前景景深虚化也会保留。
